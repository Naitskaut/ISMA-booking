# Бронь комнаты для мероприятий

Календарь, в котором жители ЖК бронируют комнату на целый день.

- Один день — одна бронь.
- Одна квартира — одна бронь в календарный месяц.
- Бронировать можно с сегодняшнего дня до конца следующего месяца.
- Все видят, какая квартира заняла день.
- Чтобы забронировать или отменить, житель вводит номер квартиры и код. Коды выдаёт админ.
- Три языка: русский, казахский, английский (переводы в `public/i18n.js`). Есть светлая и тёмная тема.
- Цвета взяты с сайта застройщика ЖК ISMA (ismainvest.kz).

Работает на Cloudflare Workers + D1 (база SQLite), бесплатный тариф.
Хранятся только номера квартир и хэши кодов, без имён и телефонов.

## Страницы

- `/` — календарь для жителей
- `/admin` — админка: брони, выдача кодов, печать карточек

## Как разместить (один раз, около 15 минут)

Нужен Node.js 18+ и бесплатный аккаунт Cloudflare (https://dash.cloudflare.com/sign-up).

```bash
npm install
npx wrangler login                      # откроет браузер, подтвердите доступ
npx wrangler d1 create zhk-booking      # создаст базу и покажет database_id
```

Скопируйте `database_id` из вывода в `wrangler.jsonc` вместо `00000000-...`.

```bash
npm run db:init:remote                  # создаст таблицы
npx wrangler secret put ADMIN_PASSWORD  # введите надёжный пароль админа (от 12 символов)
npm run deploy                          # покажет адрес сайта: https://zhk-booking.<ваш-поддомен>.workers.dev
```

После обновления кода достаточно снова выполнить `npm run deploy`.

## Первый запуск

1. Откройте `<адрес>/admin` и войдите с паролем.
2. «Квартиры и коды»: укажите диапазон 1–500 и нажмите «Создать коды».
   Если номера квартир повторяются в разных блоках, добавляйте каждый блок отдельно с приставкой (`1-`, `2-`…).
3. Нажмите «Печать карточек»: получится лист с отрезными карточками «квартира + код + адрес сайта».
   Разложите карточки по почтовым ящикам. Ещё сохраните CSV, коды показываются только один раз.
4. Если житель потерял код или код узнали посторонние, нажмите «Одна квартира» → «Новый код».

## Защита

- Коды хранятся в базе только в виде хэшей.
- После 10 неверных кодов квартира блокируется на 15 минут. Так же блокируется вход в админку с одного IP.

## Настройки (`wrangler.jsonc` → `vars`)

- `TZ_OFFSET_HOURS`: часовой пояс, по умолчанию `5` (Казахстан).
- `MONTHS_AHEAD`: на сколько месяцев вперёд открыта бронь, по умолчанию `1` (текущий + следующий).

## Локальный запуск

```bash
echo ADMIN_PASSWORD=test > .dev.vars
npm run db:init:local
npm run dev                             # http://localhost:8787
```
